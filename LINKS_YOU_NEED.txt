                    🔗 CHATZEN - LINKS YOU NEED
═══════════════════════════════════════════════════════════════

📋 COPY THESE LINKS AND OPEN THEM IN YOUR BROWSER:

1️⃣ MONGODB ATLAS (Database - REQUIRED)
   Link: https://cloud.mongodb.com
   What to do:
   - Sign up for free account
   - Create M0 cluster (free tier)
   - Get connection string
   - Whitelist IP: 0.0.0.0/0

2️⃣ OLLAMA (AI - RECOMMENDED, FREE)
   Link: https://ollama.com
   What to do:
   - Download for your OS
   - Install the application
   - Run: ollama run llama3.2
   - Verify: curl http://localhost:11434/api/tags

3️⃣ OPENAI (AI - ALTERNATIVE, PAID)
   Link: https://platform.openai.com/api-keys
   What to do:
   - Sign up / Login
   - Create new API key
   - Copy key (starts with sk-proj-)
   - Add to .env file

═══════════════════════════════════════════════════════════════

📝 WHAT TO PUT IN YOUR .env FILE:

Location: -ChatZen/Backend/.env

MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/chatzen
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2

(Or if using OpenAI instead of Ollama:)
OPENAI_API_KEY=sk-proj-your-key-here

═══════════════════════════════════════════════════════════════

✅ QUICK START COMMANDS:

cd -ChatZen/Backend && npm install
cd ../Frontend && npm install

Terminal 1: cd -ChatZen/Backend && npm run dev
Terminal 2: cd -ChatZen/Frontend && npm run dev

Open: http://localhost:5173
