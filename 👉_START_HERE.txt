🤖 AI SETUP (OPTIONAL):

   The app works perfectly without AI in demo mode.
   
   To add AI features:
   
   OPTION 1: Ollama (Free, Local)
   ───────────────────────────────
   1. Install from: https://ollama.com
   2. Run: ollama pull llama3.2
   3. Restart ChatZen
   
   OPTION 2: OpenAI (Paid)
   ───────────────────────
   1. Get API key from: https://platform.openai.com
   2. Edit Backend/.env
   3. Add: OPENAI_API_KEY=your-key
   4. Restart backend


🐛 TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════

   Problem: Port already in use
   Solution: netstat -ano | findstr :8080
            taskkill /PID <PID> /F
   
   Problem: Dependencies missing
   Solution: Run test-setup.bat
   
   Problem: Backend won't start
   Solution: Check Backend/.env exists
   
   Problem: Frontend won't start
   Solution: Check Frontend/node_modules exists
