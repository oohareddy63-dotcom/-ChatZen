# 📚 ChatZen Documentation Index

Complete guide to all documentation files and their purposes.

---

## 🚀 Quick Start Files

### 1. 👉_START_HERE.txt
**Purpose:** Visual quick reference guide  
**When to use:** First time running the app  
**Content:** ASCII art guide with all essential info  
**Format:** Plain text for easy viewing

### 2. 🚀_RUN_THIS.bat
**Purpose:** Interactive launcher with menu  
**When to use:** Every time you want to start ChatZen  
**Features:**
- Start ChatZen
- Verify setup
- Read documentation
- User-friendly menu

### 3. start-chatzen.bat
**Purpose:** Direct startup script  
**When to use:** Quick start without menu  
**Features:**
- Checks Ollama (optional)
- Verifies configuration
- Starts both servers
- Opens browser

### 4. test-setup.bat
**Purpose:** Setup verification script  
**When to use:** First time or troubleshooting  
**Features:**
- Checks Node.js
- Verifies dependencies
- Checks configuration
- Installs missing packages
